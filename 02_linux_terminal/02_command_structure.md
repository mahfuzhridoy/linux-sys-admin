# Linux Command Structure
The linux command structue follows the command then otion after that, argument. for example: ```ping -c 1 8.8.8.8```. Here, the name of the command is ```ping```, ```-c``` is the option and ```1``` is the option value. Lastly ```8.8.8.8``` is the argument. 

*[Note: The option changes how a command behaves, while an argument specifies what the command acts upon.]* 

the commands, options, and arguments are separated by a white space. Very first the option comes but no specific order for option and arguments. but as standard structure the options are written between the arguments and command.

Some commands must require some options or arguments but some does not need this. For example: ```ls``` does not require any options or arguments but ```ping``` command can not be run without the argument but option.

The options can be grouped or written separately like ```ls -l -a``` and ```ls -la``` both works same.

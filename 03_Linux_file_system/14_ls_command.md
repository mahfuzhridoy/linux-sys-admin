# The ls command
It is the most used command in linux OS. It has many options helpful for a linux system administrator. These are:

- `-l` long list shows all the informations.
- `-a` shows all files including hidden contents.
- `-d` shows the details about directory not file.
- `-1` Shows the output ina  single column.
- `-h` Shows the file size in human readable format.
- `-S` sorts file by size and largest will show first.
- `-X` sort by extensions.
- `ls --hide=*.conf /etc/` will hide all the files with .conf extension.
- `-R` list the files recursively.



## Directory usage 
`du` to show the real size of a directory. for example: `du -sh /etc/`

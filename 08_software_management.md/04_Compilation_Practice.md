# Practice source code compilation
Compiling a software using source code follows some staeps, which are:
1. Downloading source code
2. Verifying integrity
3. Unzipping the source file
4. Running configure script
5. Running make

> For practice, ProFTPD ftp server is used

### Step 1: Downloading the source code
To download the source code using a link, The `wget` tool can be used. Downloading source code with wget: `wget -c ftp://ftp.proftpd.org/distrib/source/proftpd-1.3.9d.tar.gz`

### Step 2: Verifying integrity using md5 hash
The source code providers also provide hash on its web pages, after downloading the source the hash calculation and then comparing it with the provider hash is highly recommended. 

To do this, `md5sum [downloaded file name]` command can be used to calcultae md5 hash and then compare with the original hash published by the source code providers.

If they are same then there is no problem.

### Step 3: Unzipping the source
Unzipping can be done in many ways like using GUI tool or command line tool. For command line unzip `tar -xzvf [file name]`. Then a new directory that contains the source code will be created with the same name as tar gz file

### Step 4: Running configure script
Once unzipping is done, the newly created directory will contain many files. The sorce code are stored inside src directory. And there is also an executable file called `configure`. To learn more about configure run `./configure --help`. 

the configure executable is not in a environment PATH variable. so it needs to be run with a prefixed `./` if on the same directory or the absolute file path to the configure script.

Some most important options for configure:
* `--prefix=[path]` specifies on which directory the software will be installed. If not used then the application will be installed into standard directores like /bin, /usr/bin, /etc and override any other files with the same name. This could break the system

* `--enable-*` enables a feature.

* `--disable-*` to disable a feature specified by name.

* `--with-*` to build with a particular dependency or library.



**Running the configure:** `./configure --prefix=/opt/proftpd`. This will install the file to the /opt/proftpd directory. The proftpd directory will be automatically created. 

> It is recommended to install the programs that are compiled and are not controlled by the package manager is in the /opt directory.

> Note: If any error is found then solving the error before moving to next step is required.

When compiling the software manually, the user needs to take care of dependencied manually aswell.


### Step 5: Running make
make is a gnu utility that will build the application. It will take a collection of source files and metadata and transform them into the final product. It does the real compilation by invoking the gnu c compiler multiple times.

To compile the program make will use a file called Makefile thats inside the current directory. This frile was generated by configure and contains details about how the final product should be.

To run make simply run `make` in the terminal.

If there are error while running make. solve the errors, then run `make clean` and run make again.

### Step 6: Running make install
This is the final step where the program will be installed. This will install the program into directory specified earlier with the configure script. and it will move all the files there.

run command: `sudo make install`

Once the program is installed, the sources are not required any more and can be removed. 

The installation process is complete. All the files are now stored in the installed directory (/opt/proftpd) including config files. To remove the application just remove the directory and its done.

#

*The proftpd executable file is the server. running it will start the server. *

> This server can not be controlled using systemctl like the applications installed using package manager. To start run the executable, to stop kill the process using kill or pkill command.

## Oneliner

The steps 4, 5, and 6 can be done using one line of command from inside the extracted directory.

`./configure --prefix=/opt/proftpd && make && sudo make install`

> The steps described above is applicable for most standard softwares. If there are any differen approaces, a readme file will be included to guide the installation inside the directory or inside the src directory inside it.
